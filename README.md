## A Few Things About My Work

I care a lot about building things that are actually maintainable.

That means reusable components instead of duplicated UI, sensible
architecture instead of unnecessary complexity, good API boundaries,
testing where it matters, and making sure the application remains easy
to work on as it grows.

I've also spent a lot of time working with existing systems and
integrating new functionality into them, which has taught me that
software development isn't always about starting from scratch.

Sometimes the interesting part is figuring out how to make five
different systems work together without breaking everything. 😄
